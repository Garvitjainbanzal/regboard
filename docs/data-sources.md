# Data sources

`Shared/CommonWords.swift` is generated by `tools/build_wordlist.py` and only weights which letter is likely next when
sizing invisible tap zones. It is never used to suggest or change text; nothing the user types is stored.

| Data | Source | Licence |
| --- | --- | --- |
| English, top 12,000 words with frequencies | Peter Norvig, `count_1w.txt` (Google Web Trillion Word Corpus), https://norvig.com/ngrams/ | MIT |
| Hinglish, ~440 common words spelled as people type them | `tools/hinglish_words.txt`, compiled for this project | project's own |

Evaluated and rejected: ai4bharat Aksharantar and hermitdave FrequencyWords for Hinglish. Aksharantar is mostly rare words and
names with machine-style romanisations (common words such as "hai"/"kya" are missing or misspelled), and both carry
share-alike (CC BY-SA) terms.
