# Laptop-Free iOS Deployment with SideStore

This document covers the complete setup for building RegBoard on GitHub Actions,
publishing it as a GitHub Release, and installing/refreshing it on your iPhone
via SideStore — with no laptop required after the one-time setup.

## Honest limitations of a free Apple ID

| Feature | Free Apple ID | Paid ($99/year) |
|---|---|---|
| Sideload apps | ✅ Up to 3 apps | ✅ Unlimited |
| App expiry | ❌ 7 days | ✅ 1 year |
| Refresh without Mac | ✅ SideStore handles this | ✅ |
| App Groups entitlement | ❌ **Not supported** | ✅ |
| Push notifications | ❌ | ✅ |
| iCloud entitlements | ❌ | ✅ |

### App Groups — the important caveat for RegBoard

RegBoard uses `group.com.regboard.regboard` (App Groups) so the companion app
and keyboard extension can share `UserDefaults`. **A free Apple ID cannot
provision App Groups.**

What this means in practice when sideloaded via SideStore:

- The keyboard extension still **works fully** — all typing, gestures, bigram
  engine, and UI features function normally.
- Settings changed in the companion app **will not sync to the keyboard** unless
  the user enables Full Access in iOS Settings AND you change `SettingsStore` to
  fall back to standard `UserDefaults` when the App Group suite is unavailable.
- The companion app will load and show the settings UI, but changes won't reach
  the keyboard.

**Workaround already in the code:** `SettingsStore.init()` already falls back to
`.standard` UserDefaults when the App Group suite is unavailable:

```swift
public convenience init() {
    self.init(defaults: UserDefaults(suiteName: SettingsStore.appGroupID) ?? .standard)
}
```

This means both targets will use standard (non-shared) UserDefaults when the App
Group provisioning fails, and the keyboard will use its own default settings.
This is acceptable for sideloaded use.

## Part 1 — One-time Mac setup (required once, then never again)

### Step 1: Install SideStore on your iPhone

SideStore itself must be sideloaded. The easiest first install uses AltStore on
your Mac (free):

1. Download AltServer for Mac from https://altstore.io
2. Connect iPhone to Mac via USB.
3. Open AltServer, click the tray icon → Install AltStore → choose your iPhone.
4. On your iPhone, go to **Settings → General → VPN & Device Management**, trust
   your Apple ID certificate.
5. Open AltStore on your iPhone, go to **Browse → Sources**, add:
   `https://community.altstore.io/source` (the official AltStore community source)
6. Find **SideStore** in the source and install it.
7. Trust SideStore the same way in Settings → VPN & Device Management.

> **Why this one-time Mac step?** AltStore (running on Mac) does the initial
> signing of SideStore itself. After that, SideStore is self-refreshing.

### Step 2: Generate a WireGuard / pairing file

SideStore uses a pairing file to talk to your iPhone over Wi-Fi without a Mac.

1. On your Mac, install `jitterbugpair`:
   ```bash
   brew install jitterbugpair
   # or download from: https://github.com/osy/Jitterbug/releases
   ```
2. Connect your iPhone via USB (just for this step).
3. Run:
   ```bash
   jitterbugpair
   ```
4. This creates a `.mobiledevicepairing` file (or `.pairing` depending on version)
   in the current directory.
5. **Keep this file secret** — it gives Wi-Fi access to your device.

### Step 3: Import the pairing file into SideStore

1. Transfer the pairing file to your iPhone (AirDrop, Files app, etc.).
2. Open SideStore → Settings → **Import Pairing File** → select the file.
3. SideStore will now be able to reach your iPhone over Wi-Fi for refreshes.

### Step 4: Enable SideStore's WireGuard VPN

SideStore uses a local WireGuard tunnel to simulate the USB connection Apple
requires. When you open SideStore, it asks to configure a VPN profile — allow it.
This VPN only routes to your own device (localhost tunnel) and does not send any
traffic externally.

## Part 2 — GitHub repository setup

### Step 5: Update altsource.json with your username

Replace `YOUR_GITHUB_USERNAME` in `altsource.json` with your actual GitHub
username. Commit and push.

```bash
# Example — replace with your actual username
sed -i 's/YOUR_GITHUB_USERNAME/myusername/g' altsource.json
git add altsource.json
git commit -m "chore: set GitHub username in altsource.json"
git push
```

### Step 6: Configure GitHub repository secrets

The workflow needs write access to create releases, which is handled
automatically by `GITHUB_TOKEN` (no setup needed). No additional secrets are
required because signing happens on-device via SideStore.

If you ever want to enable **re-signing in CI** (not recommended for a free
Apple ID but documented here for completeness), you would need:

| Secret name | Value | How to get it |
|---|---|---|
| `APPLE_ID` | your-email@icloud.com | Your Apple ID email |
| `APPLE_ID_PASSWORD` | app-specific password | appleid.apple.com → Security → App-Specific Passwords |
| `TEAM_ID` | 10-character string | developer.apple.com → Account → Membership (or free: Xcode → Preferences → Accounts) |

**These are NOT needed for the current workflow.** Signing happens on your iPhone
via SideStore, not in CI.

### Step 7: Enable GitHub Actions write permissions

1. In your GitHub repo, go to **Settings → Actions → General**.
2. Under **Workflow permissions**, select **Read and write permissions**.
3. Save.

This allows the workflow to commit `altsource.json` updates and create releases.

### Step 8: Push code and verify the workflow

```bash
git add .
git commit -m "feat: add SideStore deployment workflow"
git push origin main
```

1. Go to your repo's **Actions** tab.
2. Watch the `CI` workflow run.
3. After it completes, check **Releases** — you should see a new release with
   `RegBoard-unsigned.ipa` as an asset.
4. Check the repo root — `altsource.json` should have been updated with the new
   version and download URL.

## Part 3 — Installing RegBoard via SideStore (phone-only)

### Step 9: Add the RegBoard source to SideStore

1. Open **SideStore** on your iPhone.
2. Tap **Sources** (bottom tab) → **+** (top right).
3. Enter your source URL:
   ```
   https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/regboard/main/altsource.json
   ```
4. Tap **Add Source**. SideStore fetches the JSON and shows RegBoard in the list.

### Step 10: Install RegBoard

1. In SideStore → **Browse**, find RegBoard.
2. Tap **Free** → **Install**.
3. SideStore downloads the IPA from GitHub, signs it with your Apple ID, and
   installs it.
4. Go to **Settings → General → VPN & Device Management**, trust the certificate.
5. Enable the keyboard: **Settings → General → Keyboard → Keyboards → Add New
   Keyboard → RegBoard**.

### Step 11: Install new builds (no laptop)

When a new version is pushed to `main`:

1. GitHub Actions builds the IPA and creates a new release.
2. `altsource.json` is updated automatically with the new download URL and version.
3. On your iPhone, open **SideStore → Sources** → pull to refresh.
4. If a new version is available, an **Update** button appears next to RegBoard.
5. Tap **Update**. SideStore downloads, signs, and installs the new IPA.

> **This is the critical distinction:** Installing a *new build* replaces the app.
> Refreshing *keeps the installed app* but re-signs it to reset the 7-day clock.

## Part 4 — Refreshing signing (the 7-day problem, solved)

### How the 7-day expiry works

Apple's free provisioning profiles expire after 7 days. When the profile expires,
the app shows "cannot be opened" and the keyboard extension stops loading. The
app's data is not lost — only the signing needs renewal.

### How SideStore refreshes without a Mac

SideStore maintains a local WireGuard tunnel that emulates the trusted USB
connection Apple's provisioning servers require. When you tap **Refresh All**:

1. SideStore connects through the WireGuard tunnel.
2. It re-signs all installed apps using your Apple ID.
3. The provisioning profile is renewed for another 7 days.
4. No Mac, no USB cable needed.

### Automatic refresh

SideStore supports **background refresh** via its VPN extension:

1. In SideStore → **Settings**, enable **Background Refresh**.
2. SideStore will attempt to refresh apps automatically when connected to Wi-Fi,
   before the 7-day window closes.

> **Requirement:** Your iPhone and a computer running SideServer (a lightweight
> companion for SideStore, separate from AltServer) must be on the same Wi-Fi
> network, OR you must use SideStore's WireGuard tunnel mode which works over
> any network. The WireGuard mode requires the pairing file from Step 2.

### Manual refresh (always works)

Open **SideStore → My Apps** → long-press RegBoard → **Refresh**. Or tap
**Refresh All** to renew every sideloaded app at once.

## Part 5 — Troubleshooting

### "App could not be installed: An error occurred" during SideStore install

**Cause:** The unsigned IPA contains entitlements that a free Apple ID cannot
provision (most commonly App Groups).

**Fix:** SideStore/AltStore automatically strips unsupported entitlements during
signing. If it fails entirely, check SideStore's error log. You can also
manually strip entitlements before packaging using `ldid` or `codesign` in the
workflow (see below).

**Entitlement stripping in the workflow** (add after the zip step if needed):

```yaml
- name: Strip unsupported entitlements for free Apple ID
  run: |
    # Remove App Groups entitlement from both targets so free Apple ID
    # provisioning succeeds. Data sharing between app and keyboard will
    # fall back to standard UserDefaults (already handled in code).
    APP="build/Build/Products/Release-iphoneos/RegBoard.app"
    KEYBOARD="$APP/PlugIns/RegBoardKeyboard.appex"
    # Write minimal entitlements files
    cat > /tmp/app.entitlements.plist <<'EOF'
    <?xml version="1.0" encoding="UTF-8"?>
    <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
    <plist version="1.0"><dict></dict></plist>
    EOF
    cp /tmp/app.entitlements.plist /tmp/keyboard.entitlements.plist
    # codesign --remove-signature is enough; SideStore re-signs with its own profile
    codesign --remove-signature "$KEYBOARD" 2>/dev/null || true
    codesign --remove-signature "$APP" 2>/dev/null || true
```

### "Profile is not eligible for this device"

**Cause:** The bundle ID in the IPA doesn't match the one registered under your
free Apple ID in Xcode.

**Fix:** SideStore registers bundle IDs automatically when it signs. If it fails,
open Xcode on your Mac, add your Apple ID to Preferences → Accounts, and let
Xcode generate a provisioning profile for `com.regboard.regboard` once. Then
SideStore can use it.

### "App has expired" after 7 days

**Fix:** Open SideStore → My Apps → Refresh All. Done. No laptop needed.

### SideStore can't reach my device for refresh

**Causes and fixes:**

| Symptom | Likely cause | Fix |
|---|---|---|
| "Could not connect" | WireGuard VPN not running | Open SideStore; it auto-enables the VPN on launch |
| Refresh fails silently | Pairing file expired | Generate a new pairing file on Mac (Step 2), re-import |
| Background refresh not working | Low Power Mode on | Disable Low Power Mode, or do a manual refresh |
| VPN profile got deleted | Reset network settings | Re-allow VPN in SideStore settings |

### GitHub Actions workflow fails at "Create GitHub Release"

**Cause:** Insufficient permissions.

**Fix:** Settings → Actions → General → Workflow permissions → Read and write.

### `altsource.json` not updating

**Cause:** The push back to `main` in CI fails if branch protection rules
require a PR. 

**Fix:** Add `github-actions[bot]` as a bypass actor in your branch protection
rules, or disable branch protection for the `altsource.json` file specifically.

### Build fails with "no such module 'RegBoardCore'"

The tests import the module conditionally:
```swift
#if canImport(RegBoardCore)
@testable import RegBoardCore
#else
@testable import RegBoard
#endif
```
This is already handled. If the build fails, ensure the scheme name in
`xcodebuild` matches `project.yml`: it should be `RegBoard`.

## Summary: what happens after initial setup

| Event | What happens | Manual action needed? |
|---|---|---|
| Push to `main` | CI builds IPA, creates Release, updates altsource.json | None |
| Check for updates | Open SideStore → pull to refresh Sources | Tap Update |
| Install new build | SideStore downloads, signs, installs IPA | Tap Update |
| 7 days pass | App still works until certificate expires | None (background refresh) |
| Certificate expired | Open SideStore → Refresh All | Tap Refresh All |
| New pairing needed | Rare; only if device is unpaired | USB to Mac once |
